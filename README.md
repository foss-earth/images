@foss-earth/images provides pure common image contracts, JPEG/PNG header checks, exact byte arithmetic, shared reservations and session queues, and revision-keyed persistent media storage. The host constructs one createImageSessionBroker and supplies it to every representation. It tracks aggregate encoded, decoded, source GPU and outstanding upload bytes; replacement overlap is a subset of the source GPU limit. No broker creates a renderer or requests frames.

The root is pure. ./browser contains the IndexedDB adapter; createMediaStore receives its open port explicitly. ./node contains the existing JPEG/PNG codecs, source orientation/colour normalization and linear-light helpers. It contains no spatial representation preparation. Pure source sampling, file enumeration, validation and estimates are contributed by representation owners through RepresentationHooks. There is no built-in representation catalogue in this package.

Version 0.1.0 is a local preparation candidate. Build with npm run build, test with npm test, and run npm run ci for final checks. Required shared CI conformance and publication lineage are pending the Platform/coordinator pins. This package is not accepted for consumer adoption yet. Existing foss-earth/scenes remains the compatibility surface until the viewer/scene packages migrate together.

Limits are supplied in real bytes/counts by the host settings registry. Unknown projections are handled by scenes/360; this package adds no projection support. JPEG/PNG are the only existing codecs. Synthetic cardinal-grid fixture bytes were generated by the original Earth example tool; source hashes are recorded in PROVENANCE.json. No campus photographs are included.
